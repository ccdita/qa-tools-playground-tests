# qa-tools-playground-tests
Tests written for [QATools Playground Shop by Hariprasad Srinivas](https://playground.qatools.dev/products). This System Under Test (SUT) is a dummy app with tricky widgets, an API playground, click-to-inspect locator coach, verifiable challenges, and a Locators Game. Every interactive element is namespaced with stable data-testid, aria-label, and role + name.
