# qa-tools-playground-tests
Tests written for [QATools Playground by Hariprasad Srinivas](https://playground.qatools.dev/). This SUT is a practice playground with two dummy apps (Shop + Clinic), tricky widgets, an API playground, click-to-inspect locator coach, verifiable challenges, and a Locators Game. Every interactive element is namespaced with stable data-testid, aria-label, and role + name.
